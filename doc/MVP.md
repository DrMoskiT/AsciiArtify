## 2. Демонстрація ручної синхронізації

У прикладі – заміна застарілого образу Ambassador (`quay.io/datawire/ambassador) на власний образ, переконвертований у формат Docker Schema v2 та завантажений у Docker Hub.

![image](images/Знімок%20екрана%202025-11-23%20002828.png)

Після зміни образу ArgoCD виявив **OutOfSync**, та була виконана ручна синхронізація:

![image](images/Знімок%20екрана%202025-11-23%20004237.png)

## 3. Увімкнення автоматичної синхронізації

У ArgoCD було ввімкнено **Auto-Sync**, що дозволяє автоматично виправляти стан кластера та застосовувати зміни з Git.

![image](images/Знімок%20екрана%202025-11-23%20003920.png)

## 4. Демонстрація авто-синхронізації

Змінено параметр у Helm chart:

```
api-gateway:
  service:
    type: NodePort
```
![image](images/Знімок%20екрана%202025-11-23%20004443.png)
ArgoCD автоматично:
1. виявив зміну
2. позначив стан OutOfSync
3. виконав авто-синхронізацію
4. привів кластер до стану з Git
